## 模板引擎选型与设计提案（aurora）

- 选型结论：**路线 A = MiniJinja 2.x**（运行期热更新 + 后台可编辑；放弃编译期检查）。
- 用户明确约束：
  1. 模板必须支持运行期热更新、后台可编辑；
  2. aurora 只做「引擎封装」，具体页面/布局由应用业务负责，本项目不提供；
  3. **不做** HTML 错误页、**不做** 静态资源 serving（不引入 `tower-http/fs`）。
- 设计提案已写入 `docs/20-template-engine.md`（docs/ 在 .gitignore 中，不提交）。
- 关键设计决策：
  - feature：`template` / `template-hot-reload`（只 `dep:notify`，不捆绑 `watch`）/ `template-i18n`；不进 `standard`，进 `full`。
  - `TemplateEngine` 内部用 `ArcSwap<Environment<'static>>`（arc-swap 本就常开），**全量编译校验通过才原子切换**，坏模板保留旧环境。
  - 模板来源抽象为 `TemplateSource::load() -> Vec<(name, source)>`（FsSource / MemorySource / 业务自实现），框架不假定存储位置。
  - 不使用 `minijinja-autoreload`（会带第二份 notify，与锁定的 notify 8 分叉）。
  - i18n 桥：`Translator` 非 Send（FluentBundle，thread_local + Rc），因此**不注入对象**，注入按需查询的 `t()` 函数（捕获 `I18n` + `Locale`）。
  - 错误码新增 `ErrorCode::TEMPLATE_ERROR = 50008`（50005-50007 已占用）。
- P0 已通过（用户确认全部 5 点）：
  1. `[template].dir` 允许为空（纯业务注入）；
  2. 模板加载失败 = 启动失败（fail fast，对齐 i18n）；
  3. `ErrorCode::TEMPLATE_ERROR = 50008` 占用；
  4. `template` 不进 `standard`，只进 `full`；
  5. `minijinja = "2"` 不锁 patch。
  文档已由「待批准」改为「P0 基线」，§12 改为决策表并附「dir 空 / 目录缺失」边界说明。
- 下一步：P1 最小内核（尚未开工，等用户点头）。

## minijinja 升级 2.24 → 3.0.5（2026-11-03，用户指令）

- 实际破坏面只有 3 处，其余 API 兼容：
  1. `serde` 变可选且默认关闭 → 依赖改 `features = ["serde"]`；
  2. `loader` 特性被移除（原 no-op）→ 删掉；
  3. `Template::render` 只收 `Into<Value>`、`Value::from_serialize` 移除 → 内部改 `render(minijinja::value::Serde(&ctx))`。
- 未受影响：`ErrorKind` 变体、`set_undefined_behavior`、`set_recursion_limit`、`add_template_owned`、`AutoEscape`。
- 验证：199 单测 + 7 doctest 全绿、clippy 零告警、示例端到端不变；错误信息变好（`undefined value: \`title\` is undefined`）。
- **P2 重要影响**：3.0 内建逐模板自动重载（`path_loader` + `set_auto_reload`，共享引用下重读，无需 notify、无需重建环境）。
  代价：坏模板在请求时报错，没有「全量校验通过才生效」的护栏。P2 开工前需重新取舍这两条路线。

## P3 已落地（2026-11-03）

- 新增 `src/template/i18n.rs`（feature `template-i18n = ["template", "i18n"]`，已进 `full`）：
  `TemplateEngine::render_i18n(name, ctx, &I18n, &Locale)`。
- 实现：`t` 用 `Value::from_function` 注入（捕获 `I18n`+`Locale`，因为 `Translator` 非 Send）；
